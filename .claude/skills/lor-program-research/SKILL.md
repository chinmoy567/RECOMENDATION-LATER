# Program reference requirements research

Requirements vary by program, not just by university. Never assume; verify on the department's own admissions page.

## Steps
1. Find the program's "How to apply" / "Letters of reference" page (official `.ca` domain only).
2. Record per program:
   - number of referees (UBC: 2-4, set by program; UofT CS asks 3; McGill min. 2 professors)
   - type: academic vs professional (UofT OISE: one of each; UBC professional = supervisory, in the field)
   - format: free letter vs mandatory form/questionnaire (many UofT departments use forms)
   - submission: referee uploads via portal only (McGill, UBC); applicant cannot upload
   - letter must name the specific program; McGill: dated, less than 12 months old
   - referee deadline (ask referees 3-4+ weeks earlier than your own deadline)
   - what the committee scores (research potential, independent work, communication, teamwork)
3. Note whether the program is thesis/research (needs research-potential evidence) or course-based/professional (needs work ethic, applied skill, leadership).
4. Output a one-page `program-requirements.md` with source URLs and date checked. Flag anything unverified.

## Rules
- Cite the URL for every requirement. Mark "unverified" if it only comes from forums.
- Letters written by the applicant or relatives/friends are NOT acceptable (UBC states this). Never plan around it.
